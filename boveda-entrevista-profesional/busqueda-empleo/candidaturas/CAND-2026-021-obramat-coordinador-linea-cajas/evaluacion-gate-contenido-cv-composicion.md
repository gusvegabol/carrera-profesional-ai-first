# Evaluación del gate de contenido CV — CAND-2026-021

## Resultado técnico

`datos-generacion.json` es JSON válido y materializa el guion aprobado para
OBRAMAT. El contenido mantiene el foco en atención al cliente, cuadres de caja,
seguimiento de tareas, coordinación, pedidos, stock y ejecución de tienda.
Todas las unidades profesionales trazan al guion y a fuentes autorizadas.

| Criterio | Resultado | Evidencia |
| --- | --- | --- |
| Precondiciones, idioma y JSON | conforme | Gate de guion aprobado; idioma `es`; serialización JSON validada. |
| Datos privados | conforme | Nombre, apellido 1, email, teléfono, LinkedIn y fotografía incluidos; apellido 2 y ubicación omitidos. |
| Cobertura, orden y trazabilidad | conforme | M-001 a M-011 incluidos están materializados; M-012 y M-013 permanecen omitidos; M-014 se conserva como recurso técnico. |
| Factualidad | conforme | Se preservan cargos, fechas y alcance de HER-04, HER-06, HER-07, HER-08 y HER-10 sin incorporar hechos nuevos. |
| Vehículo y turnos | conforme | Vehículo propio procede de confirmación humana; turnos proceden de datos core. |
| Seniority, tono y primer escaneo | conforme | La apertura prioriza caja, cliente y coordinación; la dirección se limita a continuidad. |
| Restricciones y léxico | conforme | No se afirma tesorería, sistemas de caja de OBRAMAT, cargo formal de Responsable de Cajas ni movilidad por Canarias. |
| Frontera de artefacto | conforme | Solo contiene contenido CV; no incluye decisiones de composición ni acciones externas. |

## Advertencias activas

* El cargo formal de Coordinador/a de Cajas de OBRAMAT no está acreditado; se
  presenta equivalencia funcional.
* No se conocen los sistemas de caja específicos de OBRAMAT.
* La movilidad por Canarias no está confirmada.
* Los cuadres de caja no se presentan como tesorería, pagos, banca ni gestión
  integral del flujo monetario.
* La aprobación de este gate no autoriza componer el CV ni generar DOCX, PDF o
  LaTeX.
