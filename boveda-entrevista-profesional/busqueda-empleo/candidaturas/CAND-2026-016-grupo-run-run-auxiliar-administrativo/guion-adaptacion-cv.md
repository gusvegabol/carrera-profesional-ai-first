# Guion de adaptación — Auxiliar administrativo/a en Grupo Run Run

## Dirección de la candidatura

- **Puesto objetivo:** Auxiliar administrativo/a.
- **Perfil principal:** Administración.
- **Perfil secundario:** Sistemas y mejora de procesos.
- **Palabras clave:** gestión documental, archivo, facturación, contabilidad, informes, bases de datos, Excel avanzado, Word, software de gestión, digitalización, mejora de procesos, discreción y confidencialidad.
- **Nivel y riesgo:** Puesto auxiliar; riesgo alto de sobrecualificación.
- **Requisitos no acreditados:** Holded, CFGS, experiencia directa con Outlook/PowerPoint, atención telefónica específica y gestión ordinaria de proveedores/clientes.
- **Primer plano:** documentación, facturación, datos, informes, automatización, orden, trazabilidad y apoyo a departamentos.
- **No debe dominar:** dirección estratégica, compras centralizadas, marketing, finanzas corporativas, amplitud tecnológica o cargos directivos como identidad principal.

## Estructura narrativa

### Titular

Auxiliar administrativo | Gestión documental, facturación y mejora de procesos.

### Perfil

Profesional administrativo y de sistemas con experiencia en gestión documental, análisis de datos, facturación y mejora de procesos. Se priorizan método, iniciativa, discreción y capacidad para convertir información dispersa en documentación, informes y sistemas de seguimiento.

### Competencias

Gestión documental y archivo; facturación, contabilidad y gestión comercial; Excel avanzado e informes; dashboards y bases de datos; automatización administrativa; trazabilidad y protección de datos; software de gestión; mejora de procesos.
