# TEMPLATE_CARTA_PRESENTACION_FORMATO.docx

Plantilla visual coherente con el CV y basada en la identidad de `CAND-2026-010-acciona-administrativo/cv.docx`.

## Orden de sustitución

1. Completar identidad, contacto y `[FOTOGRAFÍA]` con datos autorizados. La foto es obligatoria salvo exclusión expresa. El hueco debe ser cuadrado 1:1, tomando como referencia una imagen de 270 × 270 px; cualquier reducción debe mantener ambas dimensiones proporcionales.
2. Completar `[DESTINATARIO]`, `[FECHA]`, `[ASUNTO]` y `[SALUDO]` según el canal y la información comprobada.
3. Redactar `[APERTURA]`, `[EVIDENCIA 1]`, `[EVIDENCIA 2]`, `[ENCAJE]` y `[CIERRE]` usando solo el guion y el análisis.
4. Completar `[FIRMA]` con el nombre autorizado.
5. Justificar el cuerpo, revisar el tratamiento formal y mantener una página.

La carta puede omitir evidencias del CV, pero no puede añadir hechos, herramientas, logros, requisitos cumplidos o información de empresa no respaldada.
