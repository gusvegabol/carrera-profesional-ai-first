# Caso controlado 002 — No recomendada

## Escenario

Oferta simulada de una función especializada cuya responsabilidad central exige una acreditación y experiencia profesional literal que los datos core no contienen. No existe evidencia transferible suficiente para construir una candidatura defendible.

## Decisión estratégica

`no_recomendada`

## Justificación

El encaje factual es insuficiente. Construir una candidatura normal requeriría introducir afirmaciones no acreditadas o presentar una transferencia no defendible.

## Resultado esperado y comprobado

- No crear `candidatura.md`.
- No crear guion, documentos finales ni veredicto.
- Conservar únicamente este análisis como trazabilidad de la decisión.
