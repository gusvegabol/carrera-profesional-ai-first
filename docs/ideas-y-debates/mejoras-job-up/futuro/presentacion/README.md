# Presentación externa futura de Job-up

Esta carpeta conserva, como línea futura, los playbooks y plantillas que podrían
ayudar a preparar o validar una presentación externa.

No forman parte del flujo activo de Job-up. El flujo vigente termina cuando la
candidatura está `documentalmente_completa`, con CV y carta finales aprobados y
`presentada: false`.

Estos documentos no autorizan iniciar sesión, rellenar formularios, enviar
archivos ni cambiar el estado `presentada`. Cualquier futura incorporación al
flujo requerirá un diseño y una decisión humana independientes.
